Option 2 — Shell Mode

  1. 1
    Colour ring — 72px circle. Arc = % of current colour done. Tap = open colour chooser in tray. Double-tap = jump to next stitch.
  2. 2
    Lock button — locked: canvas tap only marks; tray cannot open. Unlocked: tap anywhere to reveal tray.
  3. 3
    Undo zone — always visible; reverses last mark or drag-mark group. Swipe left on colour ring also triggers undo.
  4. 4
    Pattern canvas — tap = mark one stitch (no toggle; undo to unmark). Long-press 400ms = drag mode.
  5. 5
    Control tray — slides up to 75% height. Contains colour picker, session controls, highlight modes, tools. Drag handle to resize.
  6. 6
    Active colour header — shows current colour, stitch count, Find Next, and Nav mode button.
  7. 7
    Colour chooser grid — 5 large tiles with progress arc. Tap to switch colour and close tray.
Key changes from current UI:
Default state is zero chrome. Colour ring replaces toolbar + dock + action bar. Tap = mark only (undo to unmark). Long-press → drag mode. All controls in one slide-up tray. Lock prevents accidental reveal during stitching.
