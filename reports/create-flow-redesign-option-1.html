Design decisions
1
Side-by-side comparison — original and live preview are always both visible on the Convert screen. No toggling needed.
2
Dimensions at the top — the user's most important essential control surfaces first, before palette decisions.
3
Stash toggle with live count — "147 owned" makes the constraint feel concrete, not abstract.
4
"Apply & Edit" CTA — the only action that generates the pattern and transitions to Edit. There is no implicit mode switch.
5
Locked settings badge — in Edit mode, current conversion settings are shown read-only. "Change settings" is always available but clearly secondary.
6
No conversion controls in Edit sidebar — the toolstrip and right sidebar contain only edit tools and palette. Zero bleed between modes.
7
Palette-only sidebar in Edit — stash dots show which threads you own. No sliders, no re-generate button in this view.
