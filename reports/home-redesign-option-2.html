Option 2 — Workbench

One screen shows everything: what you're stitching, every project, this week's stitching and what to buy. Tabs go away. New users get a three-step checklist that turns the empty dashboard into a guide.

Why this direction

  • Tabs were hiding things, not organising them. Stash and Stats each held one or two numbers and a link to their real page. Small, useful summaries in a side rail ("You can start Seaside cottage today", the shopping list, this week's chart) say more than a tab of zeros.
  • An empty dashboard becomes a checklist. Instead of zeros and "No data", new users see three numbered steps. Step 1 holds the three ways to add a pattern, so there's one obvious place to begin. Steps 2 and 3 teach the Stitch Tracker and the Stash Manager by what they do.
  • Built for people with many projects. The project list is a compact table: preview, size, progress bar, when you last stitched, and one action. The button changes with the project's state (Continue, Start, View, Convert) so the label always says what will happen.
  • Search is visible. The command palette is one of stitchx's strongest features, and today it's an unlabelled magnifier icon. A real search box makes it discoverable.
  • The stash and the projects talk to each other. "You own every thread" on Seaside cottage links stash data to a decision the user makes on Home, which is what makes a dashboard worth having.

Walkthrough findings it fixes

  • F1Welcome card with pitch and Free / No account / Stays on this device chips.
  • F3 F4No tabs; Step 1 (or the Start rail for returning users) is the single way in.
  • F5 F6 F7Action-named buttons; Step 1 has one primary, and formats show as short hints.
  • F8"Practise on the demo pattern" sits at the step where you'd want it.
  • F10Labelled search box, Help, More. No project switcher on Home.
  • F11Stash and Stats become useful summaries with clear links to the full pages.
  • F12One state-aware action per row, plus a More menu.
  • F13 F14Preview, size, progress and last stitched on every row; filters; Project library link with a count.
  • F15Rows fold to two lines on phones; the rail drops below the projects.
  • F16"Now stitching" is the one place the active project appears.

Trade-offs

  • The densest of the three. It suits people with many projects and a stash, but a phone shows a long scroll, and Stash and Stats sit below the projects.
  • The rail costs data loading on Home (stash, shopping list, this week). Today that only loads when the tab opens; it would need the same lazy, after-first-paint loading.
  • A checklist can feel like homework. Step 3 is marked optional and the whole card disappears once steps 1 and 2 are done.

Build notes

  • Rail data already exists: StashBridge.getShoppingList(), ProjectStorage.getProjectsReadyToStart() and getStitchLogByDay() are what the current Stash and Stats tabs call.
  • Checklist state comes from data, not a new flag: step 1 is done when listProjects() isn't empty, and step 2 when any row has anyProgress.
