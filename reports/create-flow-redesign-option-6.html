Design decisions
1
Drawer handle always visible — the one-line strip shows the current committed settings as a badge (120×80 · 28 colours · Stash) so users always know what settings produced the current canvas.
2
Four sub-tabs inside the drawer — Dimensions / Palette / Detail / Advanced. Groups controls by mental model, works at 240 px wide without scrolling.
3
Original vs. preview side-by-side in the Dimensions tab — gives visual feedback on size without leaving the drawer or the edit mode.
4
"Apply conversion" is the only way settings affect the canvas — dragging sliders shows an orange unsaved dot on the handle, but the canvas does NOT update until Apply. No accidental generation.
5
Edit tools are always accessible — even with the drawer open, users can close it without applying (Discard) and return to editing. Canvas is never taken over by settings.
6
Edit sidebar unchanged from current design — palette chips, stash dots, colour replace. Familiar for existing users. No conversion sliders in the sidebar at all.
