Design decisions
1
Profile picker shown once per upload — appears as an overlay so the user can see their image behind it. The most relevant profile for this user is pre-highlighted based on last-used preference.
2
Live preview is always visible — the pattern canvas updates as settings change, even before Generate is clicked. The profile's defaults produce an immediate draft.
3
Profile pill in settings header — always shows the active profile. "Change" re-opens the picker. Users never lose track of which mode they are in.
4
Profile-filtered controls — Lineart/Stash hides dithering and bri/con/sat sliders (irrelevant for linework). "Customise" link reveals the full set if needed.
5
Single Generate button — generates the final pattern and enters edit mode. The live preview above is lower quality (fast path); Generate runs the full pipeline.
6
Hidden-but-accessible advanced controls — power users click "Customise" to reveal dithering, bri/con/sat, and seed. The "Detailed Photo" profile shows them by default.
