Design decisions
1
Always-visible step strip — users can see all 5 steps and click back to any completed step. Not a blocking modal that traps them in a linear sequence.
2
Palette step first-class — step 2 groups palette source, stash, max colours, and blends together. The user answers "what threads?" before "how big?"
3
Step 4 live preview is actually wired — this is the key fix over the current experimental wizard. The preview updates within 300 ms of any slider change in step 4.
4
Controls labelled for users, not engineers — "Remove noise" instead of "cleanup threshold", "Smooth edges" instead of "dithering toggle".
5
Step 5 summary confirms all choices — before Generate, the user sees a compact summary card showing every setting they chose. Last chance to go back and adjust.
6
Clean edit mode after generate — completing the wizard closes it and opens the canvas with edit tools only. No conversion sliders bleed into the edit sidebar.
7
Canvas visible behind wizard — the cross-stitchable canvas is always present in the background; the wizard doesn't feel like it hides your work.
